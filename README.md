# EduVerse – AI-Powered Smart Learning Platform

EduVerse is a comprehensive **AI-powered full-stack learning platform** designed to deliver a personalized, interactive, and productivity-driven educational experience. Built with the **MERN Stack**, the platform combines intelligent learning assistance, skill development, productivity tools, and progress tracking into a single unified ecosystem.

The project demonstrates modern full-stack development practices by integrating secure authentication, RESTful APIs, AI-powered learning modules, dashboard analytics, and scalable backend architecture.

# Installation

## Clone the Repository

```bash
git clone https://github.com/KartikeyG-world/EduVerse.git
```

## Navigate to the Project

```bash
cd EduVerse
```

## Install Backend Dependencies

```bash
cd backend
npm install
```

## Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

## Configure Environment Variables

Create a `.env` file inside the backend directory using the provided `.env.example` template.

---

# Run the Project

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```
