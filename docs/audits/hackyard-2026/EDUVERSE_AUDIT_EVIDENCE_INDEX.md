## Evidence Classification Taxonomy

- **Type A — Static Implementation Evidence:** Source code exists, is syntactically coherent, and implements the described behavior.

- **Type C — Runtime Verification:** The behavior was directly observed in an active runtime environment or API execution trace.
- **Type D — Production Verification:** The behavior was observed directly against the live, deployed production infrastructure (e.g., Railway/Vercel).
